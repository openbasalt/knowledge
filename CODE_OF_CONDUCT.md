# Code of conduct

This project follows the code of conduct of the OpenBasalt organization:
the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
as adopted for every OpenBasalt repository.

Report conduct problems privately to conduct@openbasalt.org. Security
vulnerabilities are not conduct reports; see [SECURITY.md](SECURITY.md).
